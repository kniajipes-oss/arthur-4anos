# Arthur's Spider Signal

Crie um protótipo de abertura para um convite digital interativo de aniversário infantil.

IMPORTANTE: neste primeiro momento, NÃO crie o convite completo. Quero testar apenas a experiência de abertura e a identidade visual.

Conceito

O aniversário é do Arthur, que fará 4 anos. O tema escolhido por ele é Homem-Aranha.

Não utilizar o personagem Homem-Aranha, rosto, corpo, uniforme, logotipo ou qualquer reprodução direta do personagem.

A ideia é transmitir imediatamente essa referência usando apenas elementos visuais abstratos e sofisticados: teias, uma aranha geométrica estilizada, movimento e a combinação de preto, vermelho e pequenos detalhes em azul.

Quero uma estética moderna, cinematográfica e elegante, que funcione tanto para crianças quanto para adultos.

NÃO quero aparência de desenho infantil, gibi, história em quadrinhos ou template de festa.

ABERTURA

A experiência deve acontecer em aproximadamente 3 segundos.

Começar com uma tela vertical para celular quase completamente preta, com fundo muito escuro e discreto.

Durante o primeiro instante, quase nada acontece.

Depois, uma linha fina vermelha surge no topo da tela e desce rapidamente, como se uma teia tivesse acabado de ser lançada.

A linha deve ter movimento fluido e elegante.

Ao chegar ao centro, ela dispara novos fios.

Rapidamente, várias linhas finas começam a se conectar.

Essas linhas formam uma teia geométrica sofisticada.

A composição deve crescer rapidamente, sem deixar a animação lenta.

Por aproximadamente meio segundo, a própria teia deve formar a silhueta de uma pequena aranha geométrica.

A aranha deve parecer um símbolo gráfico moderno, NÃO uma aranha infantil ou cartoon.

Logo depois, a teia deve se reorganizar e revelar a mensagem:

ARTHUR

FAZ 4!

O texto deve aparecer de forma impactante, limpa e elegante.

INTERAÇÃO

A abertura deve iniciar quando o usuário tocar na tela.

Antes do toque, mostrar apenas uma indicação muito discreta:

TOQUE PARA ENTRAR

Depois do toque, executar toda a animação.

Não criar uma sequência longa.

Não adicionar história ou narrativa.

A sensação deve ser de uma pequena surpresa visual.

DIREÇÃO DE ARTE

Paleta principal:

Preto / quase preto como base.
Vermelho como elemento de destaque.
Azul muito escuro em pequenos detalhes.
Branco para textos.

Usar bastante espaço negativo.

Utilizar linhas finas e precisas.

Evitar excesso de elementos.

Evitar vermelho ocupando toda a tela.

Evitar gradientes exagerados.

Evitar aparência de desenho animado.

Evitar balões de fala.

Evitar onomatopeias como POW, BOOM etc.

Evitar qualquer personagem.

A referência ao Homem-Aranha deve acontecer pela combinação visual de teia + aranha + cores, sem mostrar o personagem.

RESPONSIVIDADE

O protótipo deve ser pensado primeiro para celular, em formato vertical.

A animação deve funcionar bem em telas pequenas.

A experiência deve ser leve e fluida.

IMPORTANTE

Neste primeiro protótipo, não criar:

• data
• horário
• endereço
• confirmação de presença
• WhatsApp
• outras páginas

Quero avaliar SOMENTE a abertura.

O objetivo é descobrir se a sequência:

PRETO → LINHA VERMELHA → TEIA → ARANHA → ARTHUR FAZ 4!

consegue produzir o efeito "uau".

Se essa abertura funcionar, depois vamos evoluir o restante do convite mantendo exatamente essa identidade visual.
